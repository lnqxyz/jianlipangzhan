# jianlipangzhan · 监理旁站记录表生成

输入施工台账（Excel），自动取台账最新日期的记录，生成对应的旁站记录表 Word
（表 A.0.2 样式，台账来源数据红色字体）。

## 安装

把整个 `jianlipangzhan/` 目录拷入宿主技能库（WorkBuddy：`~/.workbuddy/skills/`）。

## 用法（对智能体说）

- 「把这份台账出成旁站记录表」+ 给文件
- 「出最新一天的旁站记录，台账在这里」
- 点名部分表：「只出隧道开挖和喷射混凝土」

## 分派规则（按文件名）

| 文件名含 | 出表 |
| --- | --- |
| 监理台账 / 施工台账 | 1 隧道开挖、3 超前小导管、6 二衬带模、7 喷射混凝土、9 防排水、10 超前钻孔/加深炮孔、11 槽道、12 综合接地 |
| 旁站注浆记录表 / 旁站灌注记录表 | 2 砂浆锚杆、4 中空锚杆、5 锁脚锚管 |
| 配料单及拌合物 / 拌和物 | 8 混凝土浇筑（起止时间从监理台账补） |

3 号、6 号名字带「注浆」但数据在监理台账；只给注浆台账时这两张出空表并进 missing。

## 目录

- `scripts/extract_latest.py` — 三份台账一次传，12 类各自取「本类最近一条有工序时间的记录」，输出带标红记号的 JSON（`tables[]` 恒为 12 项）
- `scripts/fill_docs.py` — 把 JSON 填进 20 源行模板，产出 raw docx
- `assets/template-20rows.docx` — 现成 20 源行模板（`<w:tr` 计数 20），不用每次重建
- `scripts/postprocess.py` — A4 版式/合并修复/一格多段/检查项/标红 上色/自检
- `scripts/fix_merge.py` — 导出 docx 合并残留空列修复
- `assets/build_form.js` — Univer 建表模板（20 源行×6 列）
- `references/table-layout.md` — 12 行版式规格
- `evals/triggers.json` — 触发评测 20 条

## 红线

台账是唯一数据源，没有的字段填「/」并留 missing 清单；编号、签字栏、落款日期留空不代填
（编号不填「/」）；交付前必须渲染核对。
